About this tracker

This tool keeps an eye on Microsoft's Azure Kubernetes Service (AKS), AKS Application Network, Azure Arc-enabled Kubernetes, AKS Arc, Kubernetes Fleet Manager documentation, Azure Container Registry (ACR), and Azure Application Gateway for Containers (AGC). AKS everywhere! It also shows the last 5 AKS and App Net release notes.

It automatically scans for changes, then uses AI to summarize and highlight updates that are most likely to matter — such as new features, deprecations, and significant content revisions.

Minor edits (like typos, formatting tweaks, and other low-impact changes) are usually filtered out. Because the process is automated, some updates may be missed or summaries may not capture every nuance.

For complete accuracy, you can always follow the provided links to the original Microsoft documentation.

With this tracker, you can:

  • Quickly scan meaningful AKS, App Net, Arc K8s, AKS Arc, ACR, AGC, and Fleet documentation changes from the past 7 days
  • Stay up to date with the latest AKS and App Net release notes without digging through every doc page
  • Search and browse CVE security data across AKS releases and VHD node images, powered by the AKS Vulnerability Data API (Public Preview)

Release 2026-09-04

AKS
View Release
📅 2026-09-09

This release introduces Kubernetes 1.37 and autoscaling for VM node pools. It also announces the retirement of Azure Linux with OS Guard.

❌

Breaking Changes

  • AKS will remove Azure Linux with OS Guard node images on March 10, 2027.
  • AKS no longer produces VHDs for Windows Server 2019 and version 23H2.
🔑

Key Features

  • Autoscaling for Virtual Machines node pools is now generally available.
  • Kubernetes patch versions 1.36.3, 1.35.7, and 1.34.10 are available.
  • On-Demand Monitor for node health checks is in preview.
💡

Good to Know

  • LocalDNS is enabled automatically for compatible cluster networking.
  • AKS rejects updates that remove IPv6 from dual-stack clusters.
  • Managed namespace creation rejects names starting with reserved prefixes.

AppNet 2026-08-19

App Net
View Release
📅 2026-08-31

AppNet is now in public preview with several updates and bug fixes.

❌

Breaking Changes

  • AppNet 1.0, 1.1, and 1.2 versions retired.
  • Moving AppNet resources across resource groups is now blocked.
🔑

Key Features

  • AppNet available in more Azure regions.
  • AppNet 1.5 updated to Istio 1.30.3.
💡

Good to Know

  • Cluster prerequisites validated at member-join time.
  • Fixed issues with member updates and version upgrades.

📅 2026-08-11

This release introduces several enhancements including Node Auto Provisioning and automatic availability zone placement.

🔑

Key Features

  • Node Auto Provisioning now supports restricted public network access
  • Automatic availability zone placement is enabled globally
  • Control-plane only upgrades to AKS Long Term Support are allowed
  • Node pool rollback feature is now generally available
  • Encryption in Transit for Azure File CSI driver is now available
