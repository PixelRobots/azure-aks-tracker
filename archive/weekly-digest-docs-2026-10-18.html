AKS Support - Fail to Mount Azure File Share

Storage ♻️ Rework Modified: 2026-10-15 18:04

Summary

The documentation now includes a new troubleshooting section for the "Mount error(22): Invalid argument" related to Azure Files in Kubernetes. It clarifies that this error often arises when the Kubernetes secret's `data` field values for `azurestorageaccountname` or `azurestorageaccountkey` are not base64 encoded, leading to a corrupted value during the mounting operation. Users are advised to either base64 encode these values or use the `stringData` field, which automatically handles encoding, to prevent this issue.
