# Get support for AKS on Azure Local | Microsoft Learn

If you encounter an issue with AKS on Azure Local, this article describes how to open a support request.

## Go to Support + Troubleshooting in the Azure portal

1. Sign in to the [Azure portal](https://portal.azure.com).
2. Browse to the subscription you're using for AKS on Azure Local. Select the subscription to open its dashboard.
3. From the **Help** menu in the left-hand navigation pane, select **Support + Troubleshooting**:

    ![Screenshot of the Azure portal Help and Support sidebar.](../../media/help-support/help-left-menu.png)
4. In the text box, briefly describe the issue type, then select **Go**:

    [![Screenshot of service type selection.](../../media/help-support/issue-help.png)](../../media/help-support/issue-help.png#lightbox)
5. If **Azure Kubernetes Service on Azure Local** doesn't appear in the list of predefined services, select **None of the above**.
6. Begin typing **Kubernetes** in the **Search Options** box of the **Select a service** dropdown.
7. Select **Azure Kubernetes Service on Azure Local** from the dropdown list.

    [![Screenshot of service selection.](../../media/help-support/new-request.png)](../../media/help-support/new-request.png#lightbox)

## Select issue type and solution

1. Select **Next**.
2. Your subscription name should auto-populate in the **Subscription** field. If it doesn't, select it from the dropdown. Then select **Next**.
3. Select one of the predefined issues, or select **None of the above** if your issue doesn't relate to a specific predefined issue. Then select **Next**:

    [![Screenshot of issue type selection.](../../media/help-support/issue-select.png)](../../media/help-support/issue-select.png#lightbox)

    If you select **None of the above**, you're prompted to select a problem type from a dropdown menu. From the dropdown, select a problem type.

    [![Screenshot of portal showing none of the above issues selected.](../../media/help-support/issues-none.png)](../../media/help-support/issues-none.png#lightbox)
4. Select **Next**.
5. Review the proposed solutions to determine if they address your issue:

    [![Screenshot of proposed solutions.](../../media/help-support/solutions-page.png)](../../media/help-support/solutions-page.png#lightbox)
6. If you made a mistake or want to choose a different problem type, select **Start again** at the top of the page. If the issues and solutions are not applicable, select **Create a support request** at the top of the page.
7. Select **Next**.
8. From the dropdown, select the **Technical** issue type:

    [![Screenshot of problem type selection.](../../media/help-support/select-type.png)](../../media/help-support/select-type.png#lightbox)
9. Your subscription name should auto-populate in the **Subscription** field. If it doesn't, select it from the dropdown.
10. Your service name should auto-populate in the **Service** field. If it doesn't, select it from the dropdown. The **Summary**, **Problem type**, and **Problem subtype** fields should also auto-populate based on your previous selections. If they don't, select the appropriate values from the dropdown menus.

    [![Screenshot showing service selection.](../../media/help-support/service-type.png)](../../media/help-support/service-type.png#lightbox)
11. Add a short description of your issue in the **Summary** field.
12. Select the appropriate **Problem type** from the dropdown menu for your issue (for example, **Setup, deployment, and configuration**).
13. Select **Next**.
14. Review the proposed **Solutions** to determine if they address your issue:

    [![Screenshot of proposed solutions.](../../media/help-support/solutions-page.png)](../../media/help-support/solutions-page.png#lightbox)
15. If the solutions are not applicable, select **Return to support request** at the top of the page.
16. Select **Next**.
17. Fill in the problem details and description in the appropriate fields:

    [![Screenshot showing details of service request.](../../media/help-support/service-request-details.png)](../../media/help-support/service-request-details.png#lightbox)
18. Scroll down and fill in your preferred support method of contact:

    [![Screenshot showing support method preferences.](../../media/help-support/service-request-support-method.png)](../../media/help-support/service-request-support-method.png#lightbox)
19. Select **Next**. Review the information you submitted. If anything is incorrect, select **Previous** and correct it. When all looks correct, select **Create**.
